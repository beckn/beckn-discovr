# v2.0.0

The Beckn Discovery Service running on **Beckn Protocol v2.0**.

## Highlights

* **Multi-modal discovery** — text / natural language, spatial (location-based), JSONPath attribute filtering, and combined queries through a single `POST /beckn/discover` endpoint.
* **Asynchronous results** — requests are acknowledged with an `ACK` and results delivered to the consumer's `bapUri` via `POST /on_discover`.
* **Provider-agnostic results** — resources from all providers in a network, with competing offers returned side by side.
* **Real-time indexing** — catalogue changes are searchable within seconds of being published.

## Protocol

* Beckn Protocol v2.0 field conventions (camelCase context, `resources`/`resourceAttributes`/`resourceIds`).
* ACK/NACK responses wrapped in a `message` object; errors use `code` / `message`.

## Upgrade notes

* No legacy v1.0 support. Requests must use Beckn v2.0 field names and a `version` of `2.0.0`.
